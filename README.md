# 🇧🇩 বাংলাদেশি জমি পরিমাপ ও ডিজিটাল রূপান্তর ক্যালকুলেটর (Bangla Land Measurement Converter)

একটি হালকা, দ্রুত এবং সম্পূর্ণ ফিচারে সমৃদ্ধ ওয়েব অ্যাপ্লিকেশন, যার মাধ্যমে বাংলাদেশের যেকোনো অঞ্চলের জমির পরিমাপ (শতক, কাঠা, বিঘা, একর, হেক্টর, কানি, ছটাক ইত্যাদি) অত্যন্ত নিখুঁতভাবে বিভিন্ন এককে রূপান্তর এবং হিসাব করা যায়।

 live ডেমো দেখার জন্য কিংবা আপনার গিটহাব পেজে হোস্ট করার জন্য এটি একক (Single) ফাইল ড্যাশবোর্ড হিসেবে প্রস্তুত করা হয়েছে।

## 🌟 মূল সুবিধাসমূহ (Features)

1. **সর্বাঙ্গীন একক রূপান্তর (Direct Unit Converter):**
   - **সাধারণ একক:** শতক/শতাংশ/ডেসিমেল, কাঠা, বিঘা, একর, হেক্টর।
   - **আঞ্চলিক ও ঐতিহ্যবাহী একক:** কানি (১২০ শতক মান), গণ্ডা, ছটাক, পাকি।
   - **দৈর্ঘ্যভিত্তিক বর্গ একক:** বর্গফুট, বর্গগজ/ইয়ার্ড, বর্গমিটার, বর্গহাত, বর্গলিংক, বর্গকিলোমিটার, বর্গমাইল।
   - **ক্ষুদ্র একক:** অযুতাংশ, করা, ক্রান্তি।

2. **আঞ্চলিক বিঘা কাস্টমাইজেশন (Regional Bigha Customization):**
   - **সরকারি প্রমিত মান:** ১ বিঘা = ৩৩ শতক।
   - **আঞ্চলিক মানসমূহ:** ১ বিঘা = ৩৫ শতক এবং ১ বিঘা = ৩০ শতক মোডে তাৎক্ষণিক রূপান্তরের সুবিধা।

3. **জমির ক্ষেত্রফল ক্যালকুলেটর (Land Area Calculator):**
   - **বিভিন্ন জ্যামিতিক আকৃতি:** আয়তাকার, বিষমবাহু চতুর্ভুজ (গড় দৈর্ঘ্য × গড় প্রস্থ) এবং ত্রিভুজাকার (হে রনস ফর্মুলা)।
   - **বিভিন্ন পরিমাপের একক সাপোর্ট:** ফুট, হাত, লিংক, গজ ও মিটার।
   - ফলাফল একযোগে বর্গফুট, শতাংশ, কাঠা এবং বিঘায় প্রদর্শন।

4. **ভূমি অভিধান ও নির্দেশিকা (Land Glossary & Reference):**
   - খতিয়ান, পর্চা, নামজারি/জমা খারিজ, দাখিলা, মৌজা, দাগ নম্বর, বয়নামা, দখলনামা, চিটা ইত্যাদি পরিভাষার সহজ বাংলা ব্যাখ্যা।

5. **সম্পূর্ণ রেসপন্সিভ এবং মডার্ন UI:**
   - মোবাইল, ট্যাবলেট এবং ডেসটপ ডিভাইসের জন্য স্বাচ্ছন্দ্যদায়ক ডিজাইন (Tailwind CSS দ্বারা চালিত)।

## 🚀 গিটহাব পেজে হোস্ট করার নির্দেশিকা (How to Host on GitHub Pages)

এই প্রজেক্টটি খুব সহজেই গিটহাব পেজে বিনামূল্যে হোস্ট করা যায়:

### ধাপ ১: রিপোজিটরি তৈরি করুন
1. [GitHub](https://github.com/)-এ লগইন করুন এবং একটি নতুন public রিপোজিটরি তৈরি করুন (যেমন: `bangla-land-converter`)।

### ধাপ ২: ফাইল আপলোড করুন
1. কোডের `land_converter.html` ফাইলটির নাম পরিবর্তন করে **`index.html`** রাখুন।
2. `index.html` এবং এই `README.md` ফাইল দুটি আপনার তৈরি করা গিটহাব রিপোজিটরিতে আপলোড/পুশ করুন।

### ধাপ ৩: GitHub Pages চালু করুন
1. আপনার রিপোজিটরির **Settings** ট্যাবে যান।
2. বামপাশের মেনু থেকে **Pages** বিকল্পে ক্লিক করুন।
3. **Build and deployment** সেকশনের অধীন **Source** হিসেবে `Deploy from a branch` নির্বাচন করুন।
4. **Branch** হিসেবে `main` (অথবা `master`) সিলেক্ট করে root (`/`) ফোল্ডার নির্বাচন করুন এবং **Save** এ ক্লিক করুন।
5. ১-২ মিনিটের মধ্যে আপনি একটি লাইভ ইউআরএল পেয়ে যাবেন (যেমন: `https://your-username.github.io/bangla-land-converter/`)।
